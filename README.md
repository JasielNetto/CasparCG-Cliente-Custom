# Template-Claude

Template de governança para projetos desenvolvidos com Claude Code.

## Princípio

O template mantém regras gerais no `CLAUDE.md` e `.claude/ENGINEERING.md`, deixando contexto específico do projeto em `PROJECT_CONTEXT.md`. Skills e agents devem ser usados somente quando necessários.

## Uso

Copie os arquivos do template para o novo projeto. Não copie a pasta `.git`; o projeto derivado deve possuir seu próprio repositório Git.
